## 四、导出为PDF方法

### 方法一：Markdown转PDF

1. **VS Code用户**：
   - 安装 Markdown PDF 插件
   - 右键点击.md文件 → 选择"Markdown: Print to PDF"

2. **Typora用户**：
   - 打开.md文件
   - 文件 → 导出为PDF

### 方法二：HTML转PDF

1. 在浏览器中打开 `数据挖掘分析报告.html`
2. 按 Ctrl+P 打印
3. 选择"另存为PDF"

### 方法三：Word排版后转PDF

1. 新建Word文档
2. 按排版建议插入各部分内容
3. 文件 → 导出为PDF
